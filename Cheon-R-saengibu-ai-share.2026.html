👋 처음이신가요? API 키 발급 가이드
과세특 AI를 쓰려면 OpenAI API 키가 필요해요 · 3분이면 끝나요
1
OpenAI 계정 만들기
platform.openai.com/signup 접속 → 구글 계정 또는 이메일로 가입해요.
(이미 ChatGPT 계정이 있으면 그 계정으로 로그인만 하시면 되고, 결제(Billing)는 별도로 등록하셔야 해요.)
2
결제수단(카드) 등록
로그인 후 우측 상단 Settings → Billing 메뉴로 이동 → Billing 바로가기
"Add payment method"에서 체크카드/신용카드 등록 → 원하는 만큼 충전(예: $5~10)도 가능해요.
3
API 키 발급
platform.openai.com/api-keys 접속 → "Create new secret key" 클릭 → 이름은 아무거나(예: 생기부AI) → 생성된 키(sk-...로 시작)를 복사해요.
⚠️ 이 키는 그 화면을 벗어나면 다시 볼 수 없으니 꼭 메모장 등에 붙여두세요.
4
이 앱에 키 붙여넣기
런처 화면의 🔑 API 설정 버튼을 눌러 복사한 키를 붙여넣고 저장하면 끝!
키는 이 기기(브라우저)에만 저장되고 외부로 전송되지 않아요.

📖 교과 세특 작성 가이드
화면 순서대로 정리했어요
1. 화면 구성
왼쪽부터 순서대로 과목 선택 → 반/학생 목록 → 입력폼 → 생성결과, 이렇게 4단으로 되어있어요.
2. 성취기준
"성취기준 선택" 버튼 → 팝업에서 다중 선택 → 각 항목 아래 "📋 성취수준 보기"로 상/중/하 참고 가능.
3. 참여도 및 태도 / 교과역량
등급(최상~최하) + 세부 태도 다중선택. 교과역량도 다중선택 가능해요.
4. 수업활동
스타터발표·문제발표·조별학습·독서탐구보고서는 토글로 켜고 끌 수 있어요. "+ 새 활동 만들기"로 이 4개 말고 다른 항목도 자유롭게 추가할 수 있어요.
⭐ 5. 엑셀 일괄 업로드 — 한 명씩 안 눌러도 돼요
학생 한 명 한 명 클릭해서 입력할 필요 없어요! 방법은:
① 반 탭에서 업로드할 반을 먼저 선택
② 각 활동 아래 "엑셀 업로드"에 파일 하나만 올리면 → 그 반 학생 전체한테 자동으로 매칭돼서 들어가요
③ 매칭 기준: 엑셀에 번호(학번) 열이 있으면 번호로, 없으면 이름으로 자동 매칭 (이름 철자만 정확하면 번호 없이도 OK)
④ 양식이 헷갈리면 "📋 양식 다운로드"로 기본 틀 받아서 채우면 돼요
⑤ 반 전체 취소하고 싶으면 "🗑️ 반 전체 초기화"
6. 희망전공 / 활동내용
전공은 프리셋 클릭 또는 직접 입력. 활동내용은 직접 타이핑 또는 "📝 템플릿" 불러오기.
7. AI 생성
"AI 세특 생성하기" = 지금 보고 있는 학생 1명만 생성. "일괄생성 모드" 토글을 켜면 체크한 여러 학생을 한 번에 생성.
8. 생성결과 확인·수정
결과창을 클릭하면 수정 팝업이 열려요. "📋 기재요령 검토" / "🎓 사정관 시뮬레이션" 버튼으로 AI 검토도 받을 수 있어요.
9. 저장 / 백업
"💾 저장" = 지금까지 입력한 데이터 전체를 파일로 백업. "📂 불러오기"로 복원. localStorage는 브라우저 지우면 날아가니, 큰 작업 전엔 저장 습관을 추천드려요.
10. API 키
상단 "🔑 API키" 클릭해서 OpenAI 키 등록/변경.
