🔗 GAS 웹앱 URL 설정
Google Apps Script URL을 입력하면 이 기기에서 해당 구글 시트로 연동돼요.
선생님마다 각자 URL을 입력하면 각자의 시트로 분리됩니다.
📤 학생 배포용 링크
아래 링크를 복사해서 학생들에게 공유하세요.
이 링크로 접속한 학생은 선생님 시트로 자동 연결됩니다.
✅ 복사됐어요!
📖 설치 가이드
▾
Step 1. GAS 파일 복사하기
  1. Google 드라이브 접속 → 새로 만들기
  2. Google Apps Script 선택
  3. 기존 코드 전체 삭제 후 배포용 코드 붙여넣기
Step 2. 웹앱으로 배포하기
  1. 상단 메뉴 배포 → 새 배포 클릭
  2. 유형 선택 → 웹 앱
  3. 액세스 권한: 모든 사용자로 설정
  4. 배포 클릭 → 권한 허용
  5. 웹앱 URL 복사
Step 3. URL 연결하기
  1. 위 새 GAS 웹앱 URL 칸에 복사한 URL 붙여넣기
  2. 연결 확인 후 저장 버튼 클릭
  3. ✅ 연결 성공 메시지 확인
  4. 생성된 학생 배포용 링크 복사해서 학생들에게 공유
💡 코드 수정이 필요한 경우 재배포 시 새 배포가 아닌 배포 관리 → 수정으로 진행해야 URL이 유지됩니다.
