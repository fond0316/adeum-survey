📈 이차함수 개요
표준형: y = a(x-p)² + q  → 꼭짓점 (p, q)
항목내용⚠️ 함정
a > 0아래로 볼록 ∪, 최솟값 존재위로 볼록이 아님!
a < 0위로 볼록 ∩, 최댓값 존재최솟값 없음
꼭짓점(-b/2a, f(-b/2a))일반형에서 직접 읽기 불가
축x = -b/2aa로 묶고 완전제곱 만들기
📐 이차방정식 핵심 공식
항목공식/내용조건⚠️ 함정
근의 공식x=(-b±√(b²-4ac))/2aa≠0a=0이면 일차방정식!
판별식 DD=b²-4ac계수 실수b가 짝수면 D/4=b'²-ac 활용
D > 0서로 다른 두 실근x축 두 점 교차두 근이 다른지 꼭 확인!
D = 0중근 (같은 두 실근)x축에 접함중근도 실근! 허근 아님
D < 0서로 다른 두 허근x축과 안 만남허근은 켤레복소수 쌍
근과 계수α+β=-b/a, αβ=c/a두 근 α,β합은 -b/a (부호 주의!)
켤레근계수 실수 → 허근은 켤레쌍a+bi → a-bi도 근계수가 실수인 경우만!
📉 이차부등식 해집합
핵심: 그래프에서 x축보다 위 → f(x)>0, 아래 → f(x)<0
조건D>0 (α<β)D=0 (중근 α)D<0⚠️ 함정
a>0, f>0x<α 또는 x>βx≠α인 모든 실수모든 실수a>0은 아래로 볼록

a<0, f>0α<x<β해 없음해 없음a<0이면 방향 반대!

📈 삼차함수 개요
일반형: y = ax³ + bx² + cx + d  (a ≠ 0)
항목내용⚠️ 함정
a > 0좌하 → 우상 방향 (↗)극값이 없을 수도 있음!
a < 0좌상 → 우하 방향 (↘)극대·극소 방향 반대
대칭성변곡점에 대해 점대칭축 대칭이 아님! 점대칭!
실근 개수반드시 실근 1개 이상허근만 있을 수 없음
📐 극대 · 극소 · 변곡점
핵심 흐름: f'(x) 구하기 → 부호변화표 → 극값 판정
개념정의/조건구하는 법⚠️ 함정
극대f'(x): + → − 으로 변화f'(x)=0 풀고 부호확인f'(a)=0 이어도 극값 아닐 수 있음!
극소f'(x): − → + 으로 변화f'(x)=0 풀고 부호확인부호가 안 바뀌면 극값 아님
변곡점f''(x)=0이고 볼록 방향 바뀜f''(x)=0 풀고 볼록성 확인f''(a)=0 만으론 부족! 방향 바뀜 확인
극값 없는 경우f'(x) 부호 안 바뀜f'(x)=3ax²+2bx+c의 D≤0단조증가/감소로 극값 없을 수 있음

핵심: 극대값 × 극소값의 부호로 실근 개수 판단!
실근 3개

📈 사차함수 개요
일반형: y = ax⁴ + bx³ + cx² + dx + e  (a ≠ 0)
항목내용⚠️ 함정
a > 0양 끝 위로 ↑↑, 최솟값 존재 가능최솟값이 반드시 있진 않음
a < 0양 끝 아래로 ↓↓, 최댓값 존재 가능양 끝 방향 동일! (이차와 다름)
극값 개수극값 최대 3개 (극대1 극소2 또는 반대)극값 1개이거나 없을 수도 있음
변곡점f''(x)=0이고 볼록 방향 바뀌는 점변곡점 최대 2개
📐 극대 · 극소 · 변곡점 (사차)
핵심 흐름: f'(x) (3차) 구하기 → 부호변화표 → 극값 판정 / f''(x) (2차) → 변곡점
개념정의/조건사차에서 특징⚠️ 함정
f'(x)3차 다항식실근 최대 3개 → 극값 최대 3개f'(x)의 실근 개수 = 극값 후보 개수
극대·극소f'(x) 부호 변화극소2·극대1 또는 극소1·극대2 패턴f'(x) 중근이면 극값 아님!
f''(x)2차 다항식변곡점 최대 2개f''(a)=0만으론 변곡점 확정 불가
대칭성b=0일 때 y축 대칭y=ax⁴+cx²+e 꼴b≠0이면 y축 대칭 아님!
