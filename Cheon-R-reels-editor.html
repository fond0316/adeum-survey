📱 앱 주소로 화면 자동 촬영 (선택)

내 앱 주소를 넣으면 AI가 기능을 파악하고, 버튼을 눌러가며 화면을 알아서 캡처해서 STEP 1에 넣어줘요. (GitHub Pages에 올린 내 앱만 가능)

짧게 3~4장
자동 5~7장
꼼꼼히 8~12장

촬영할 때 "이 탭 공유" 허용창이 한 번 떠요. 앱이 이 브라우저에 저장된 실제 데이터를 그대로 보여주니, 촬영 후 아래 미리보기에서 학생 이름 등이 보이는 장면은 ✕로 빼주세요.

📸 촬영 결과 (사진을 누르면 크게 볼 수 있고, 자막은 고칠 수 있어요. 마음에 안 드는 장면은 ✕)

1편집할 사진 / 영상 올리기

여러 장 한 번에 선택할 수 있어요. 순서는 릴스에 들어갈 순서예요 (화살표로 순서 조정 가능).

📁 탭해서 선택 하거나 파일을 여기로 드래그하세요
jpg · png · mp4 · mov 등

2원하는 느낌 정하기

참고하고 싶은 릴스 영상을 직접 저장해서 올리면 AI가 스타일을 분석해요. (인스타 링크 자동 다운로드는 정책상 지원이 안 돼서, 저장한 파일을 올려주셔야 해요 🙏) 아니면 미리 준비한 스타일 중에서 골라도 돼요.

🤖 AI 추천 스타일 (앱을 분석해서 골랐어요)

적용해도 아래 3번에서 얼마든지 다시 바꿀 수 있어요.

🎥 참고 영상 분석
✨ 스타일 프리셋
🎞️ 참고 영상 선택 (직접 저장한 mp4/mov 파일)

4편집 시작

브라우저 안에서 직접 처리해서 파일이 크면 시간이 좀 걸려요 (몇 분 정도). 이 탭을 닫지 말고 기다려주세요.

🤖 AI로 수정하기

이 앱에서 고치고 싶은 부분을 말로 설명하면, AI가 전체 코드를 다시 만들어줘요. 미리보기로 먼저 확인하고, 마음에 들면 적용하세요.
