🔗 내 구글 시트 연결

학생 기록은 선생님의 구글 시트에만 저장돼요. 아래 3단계를 따라 해 주세요. (PC 크롬 권장)

1
구글 드라이브에서 새 스프레드시트를 만들고, 메뉴 확장 프로그램 → Apps Script를 열어요.
2
기본 코드(function myFunction…)를 전부 지우고 아래 버튼으로 복사한 코드를 붙여넣은 뒤 💾 저장해요.
복사가 안 될 때: 코드 직접 복사하기
3
오른쪽 위 배포 → 새 배포 → 유형: 웹 앱 → 실행 사용자: 나 / 액세스 권한: 모든 사용자 → 배포. 권한 허용 후 나오는 웹 앱 URL(…/exec)을 아래에 붙여넣어요.

⚠️ 나중에 코드를 고칠 땐 새 배포가 아니라 배포 관리 → ✏️ 수정 → 새 버전으로 배포해야 주소가 그대로예요.
