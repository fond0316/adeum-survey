📝 등급계산기

2022 개정 교육과정 5등급제 · 반별 엑셀을 넣으면 전체 학년 기준으로 자동 계산됩니다

🔒 학생 이름·점수는 이 기기 브라우저에만 저장되고 어디로도 전송되지 않아요. 공용 컴퓨터라면 사용 후 '전체 데이터 삭제'를 눌러 주세요.

1️⃣ 명렬표 / 점수 엑셀 업로드

반별 파일 여러 개를 한 번에 올려도 되고, 한 파일 안에 시트가 여러 개(반별)여도 자동으로 다 합쳐서 인식해요. 필요한 열: 학번(또는 반+번호), 이름, 점수

학번 열이 없고 반+번호만 있는 파일에서 학번을 만들 때 써요. 학번이 있거나 나이스 일람표처럼 학년이 적힌 파일은 파일 내용이 우선이에요. '자동'은 이미 계산한 다른 탭의 학년을 따라가고, 없으면 1학년이에요.
📂 클릭해서 파일 선택 (또는 여기로 드래그)
.xlsx / .xls 파일, 여러 개 선택 가능
💡 엑셀 열 형식 자세히 보기

1️⃣ 반영비율 설정

중간고사 / 기말고사 / 수행평가 탭에서 각각 계산을 먼저 마쳐야 종합 계산을 할 수 있어요. 세 비율의 합은 100이어야 해요.
만점이 서로 다르면(예: 수행평가 40점) 꼭 만점을 정확히 입력해주세요 — 100점 기준으로 환산한 뒤에 비율을 곱해요.

2️⃣ 계산 결과 (전체 학년 통합 기준)
