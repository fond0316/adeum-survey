📤 학생 배포용 링크

아래 링크를 복사해서 학생들에게 공유하세요.
이 링크로 접속한 학생은 선생님 시트로 자동 연결됩니다.

✅ 복사됐어요!
📖 설치 가이드
▾
Step 1. GAS 파일 복사하기
  1. 구글 계정 로그인 → 구글 스프레드시트 접속 → 새 스프레드시트 만들기
  2. 상단 메뉴 확장 프로그램 → Apps Script 클릭
  3. 기존 코드 전체 삭제 후 배포용 코드 붙여넣기
Step 2. 웹앱으로 배포하기
  1. 상단 메뉴 배포 → 새 배포 클릭
  2. 유형 선택 → 웹 앱
  3. 액세스 권한: 모든 사용자로 설정
  4. 배포 클릭 → 권한 허용
  5. 웹앱 URL 복사
Step 3. URL 연결하기
  1. 위 새 GAS 웹앱 URL 칸에 복사한 URL 붙여넣기
  2. 연결 확인 후 저장 버튼 클릭
  3. ✅ 연결 성공 메시지 확인
  4. 생성된 학생 배포용 링크 복사해서 학생들에게 공유
💡 코드 수정이 필요한 경우 재배포 시 새 배포가 아닌 배포 관리 → 수정으로 진행해야 URL이 유지됩니다.

📖 사용 가이드

처음 설정할 때 이 순서대로 해주세요!

Step 1. GAS 연결하기
  1. 구글 계정 로그인 → 구글 스프레드시트 접속 → 새 스프레드시트 만들기 → 상단 메뉴 확장 프로그램 → Apps Script
  2. 기존 코드 전체 삭제 후 배포용 GAS 코드 붙여넣기 → 저장
  3. 상단 메뉴 배포 → 새 배포 클릭
  4. 유형: 웹 앱 / 액세스: 모든 사용자 → 배포 → 권한 허용
  5. 웹앱 URL 복사
  6. 관리자 화면 🔗 GAS 연결 탭에 URL 붙여넣고 연결 확인 후 저장
Step 2. 기본 정보 설정하기
  1. ⚙️ 기본 설정 탭으로 이동
  2. 선생님 이름 · 직함 입력 후 저장
  3. 비밀번호 변경 (기본값 0413)
  4. 공지 문구 입력 후 저장 (선택)
Step 3. 날짜 · 시간 추가하기
  1. 📅 날짜/시간 탭으로 이동
  2. + 날짜 추가 버튼으로 상담 날짜 추가
  3. 각 날짜마다 시작 · 종료 시간 입력 후 추가
Step 4. 학부모에게 배포하기
  1. 🔗 GAS 연결 탭으로 이동
  2. 학생 배포용 링크 복사 버튼 클릭
  3. 복사된 링크를 학부모들에게 공유
💡 GAS 코드 수정 후 재배포할 때는 새 배포가 아닌 배포 관리 → 수정으로 해야 URL이 유지돼요.
