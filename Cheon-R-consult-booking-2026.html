📖 설치 가이드
▾
Step 0. 사용자 등록 (처음 1회)
  1. 링크를 처음 열고 맨 아래 관리자를 누르면 사용자 등록 화면이 먼저 나와요

Step 1. GAS 파일 복사하기
  1. 구글 계정 로그인 → 구글 스프레드시트 접속 → 새 스프레드시트 만들기

  3. 기존 코드 전체 삭제 후 아래 코드 전체 복사 버튼으로 복사한 코드 붙여넣기 → 저장

Step 2. 웹앱으로 배포하기
  1. 상단 메뉴 배포 → 새 배포 클릭
  2. 유형 선택 → 웹 앱
  3. 액세스 권한: 모든 사용자로 설정
  4. 배포 클릭 → 권한 허용
  5. 웹앱 URL 복사
Step 3. URL 연결하기
  1. 위 새 GAS 웹앱 URL 칸에 복사한 URL 붙여넣기
  2. 연결 확인 후 저장 버튼 클릭
  3. ✅ 연결 성공 메시지 확인 (로그인 화면에서 연결했다면 처음 비밀번호는 consultbooking — 바로 새 비밀번호로 바꾸는 화면이 떠요)
  4. 생성된 학부모 배포용 링크를 링크 글자로 복사하거나 QR 이미지 저장으로 학부모님들께 공유
💡 코드 수정이 필요한 경우 재배포 시 새 배포가 아닌 배포 관리 → 수정으로 진행해야 URL이 유지됩니다.

📄 개인정보 처리방침

학부모 상담 예약(Made by Cheon_R)을 만든 개발자가 사용자 등록·후기와 관련해 받는 정보를 어떻게 다루는지 알려 드려요. (시행일 2026-10-07)

1. 받는 정보와 목적

  • 필수: 학교의 지역·학교급 (예: 서울 · 고등학교)
  • 필수: 아이디 — 사용자를 구분하고, 삭제·문의 요청 때 누구의 정보인지 확인하는 데 써요. 실명이 아닌 아이디를 권해요.
  • 자동: 앱 사용 기록(접속한 날짜·횟수)
  • 선택 제출: 후기·개선점
  • 이용 목적: 이용 현황 파악, 문의 응대, 앱 개선

2. 보유 기간과 파기

  • 앱을 운영하는 동안 보관해요. 삭제를 요청하시면 지체 없이 등록부(구글 시트)에서 지워요.

3. 제3자 제공·소개 자료 활용

  • 제3자에게 제공하지 않아요. 소개 자료에는 숫자 통계로만 쓰고, 후기 인용은 후기를 쓰실 때 따로 허락하신 경우에만 해요.

4. 저장 장소 (해외 서버 포함)

  • 개발자의 구글 시트·구글 Apps Script에 저장돼요. 구글(Google)의 서버를 쓰며, 서버가 해외에 있을 수 있어요. 개발자 본인만 열어 봐요.

5. 학부모·학생 정보

  • 학부모·학생의 이름, 연락처, 상담 희망 내용은 개발자에게 전달되지 않아요. 각 선생님 본인의 구글 시트에만 저장되고, 선생님이 관리·삭제해요.

6. 동의 거부 권리와 불이익

  • 동의하지 않을 수 있어요. 다만 동의하지 않으면 사용자 등록을 할 수 없어서 관리자 기능을 쓸 수 없어요.
