📤 학생 배포용 링크

✅ 복사됐어요!
📖 설치 가이드
▾
Step 1. GAS 파일 복사하기
  1. 구글 스프레드시트 → 확장 프로그램 → Apps Script
  2. 기존 코드 삭제 후 배포용 GAS 코드 붙여넣기
Step 2. 웹앱으로 배포하기
  1. 배포 → 새 배포 → 웹 앱
  2. 액세스: 모든 사용자 → 배포 → 권한 허용
  3. 웹앱 URL 복사
Step 3. URL 연결 후 시간대 설정
  1. GAS 연결 탭에 URL 붙여넣고 저장
  2. 🕐 시간대 설정 탭에서 프리셋 확인/수정
  3. 📅 날짜 생성 탭에서 날짜 범위 입력 → 슬롯 자동 생성
💡 코드 수정 후 재배포 시 새 배포가 아닌 배포 관리 → 수정으로 해야 URL이 유지돼요.

📖 사용 가이드
Step 1. GAS 연결
  1. 구글 스프레드시트 → Apps Script → GAS 코드 붙여넣기 → 저장
  2. 배포 → 새 배포 → 웹 앱 → 모든 사용자 → 배포
  3. GAS 연결 탭에 URL 붙여넣고 저장
Step 2. 시간대 설정
  1. 🕐 시간대 설정 탭으로 이동
  2. 각 프리셋의 시작시간 · 요일 체크박스 확인/수정
  3. 💾 프리셋 저장 클릭
Step 3. 날짜 생성 & 배포
  1. 📅 날짜 생성 탭에서 시작일~종료일 입력
  2. ✨ 슬롯 자동 생성 클릭
  3. GAS 연결 탭에서 학생 배포용 링크 복사 → 학생 공유
