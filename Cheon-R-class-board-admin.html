📝 사용자 등록

처음 한 번만 입력하면 돼요. 입력한 정보는 사용 현황 파악을 위해 개발자에게 전달돼요. (다음 단계에서 구글 시트를 연결하면 등록이 자동으로 완료돼요)

자세히 보기 ▾
  • 수집 항목: 이름, 학교, 학급, 앱 사용 기록(접속한 날짜·횟수), 남겨 주신 후기·개선점
  • 이용 목적: 이용 현황 파악, 문의 응대, 앱 개선, 개발자의 활동 기록 정리. 소개 자료에는 숫자 통계로만 쓰고, 이름·학교가 드러나게 쓰지 않아요. (후기 인용은 후기를 쓰실 때 따로 허락하신 경우에만)
  • 보유 기간: 앱을 운영하는 동안. 삭제를 요청하시면 지체 없이 삭제해요.
  • 삭제·문의: ⚙️ 설정 탭의 [✉️ 문의하기]로 요청해 주세요.
  • 학생 정보: 학생의 이름·학번·공지 내용은 개발자에게 전달되지 않아요. (선생님 본인의 구글 시트에만 저장돼요) 학생이 직접 남기는 후기·개선점, 그리고 학생 앱이 열린 기기 수(하루 1번, 숫자로만)만 이름 없이 전달되고, 선생님이 💬 후기 탭에서 언제든 끌 수 있어요.

필수 동의예요. 동의하지 않으시면 사용자 등록을 할 수 없어서 앱을 쓸 수 없어요.

🔗 구글 시트 연결

Apps Script에서 배포한 웹 앱 URL을 붙여 넣어 주세요.

📖 CLASS BOARD 설치 가이드

Step 1. 구글 시트 만들기
  1. 구글 계정 로그인 → 구글 스프레드시트 접속 → 새 스프레드시트 만들기
  2. 이름은 자유롭게 (예: CLASS BOARD 2026 1-4)
  3. 시트 탭은 직접 만들 필요 없어요. 첫 연결 때 자동으로 생겨요.
Step 2. GAS 코드 붙여넣기
  1. 시트 메뉴 확장 프로그램 → Apps Script
  2. 편집기에 있는 기본 코드를 Ctrl+A로 전부 지우기
  3. 아래 코드 전체 복사 버튼 → 붙여넣기 → 저장(💾)

🔄 이미 쓰고 계신다면: 앱이 업데이트되면 관리 화면 맨 위에 🔔 알림이 떠요. 그때도 여기서 새 코드를 복사해서 붙여넣고 수정 배포하면 돼요.

Step 3. 웹 앱으로 배포
  1. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
  2. 실행 사용자: 나 / 액세스 권한: 모든 사용자 → 배포
  3. 권한 요청 창: 내 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용
  4. 마지막 화면의 …/exec로 끝나는 웹 앱 URL 복사
Step 4. 연결하기
  1. 링크를 처음 열면 사용자 등록(이름·학교·학급)부터 입력해요
  2. 다음 화면에서 ← 돌아가기 → 복사한 URL 붙여넣기 → 연결하기
  3. 처음 비밀번호 classboard로 로그인
  4. 바로 새 비밀번호로 바꾸는 화면이 떠요 (꼭 바꿔야 다음으로 넘어가요)
  5. 사용자 등록(이름·학교·학급)은 링크를 처음 열 때 이미 입력했기 때문에 여기서 자동으로 완료돼요
⚠️ 링크를 열었는데 연결 화면 없이 로그인 화면이 바로 뜬다면, 이 기기에서 다른 선생님이 쓰던 연결이 남아 있는 거예요. (예: 교무실 공용 PC) 로그인 화면의 [연결 주소 변경]을 눌러 내 URL을 붙여넣어 주세요.
Step 5. 첫 설정
  1. 학년도·학급 이름·회장 코드 입력 → 설정 저장
  2. 👥 명단 탭에 학번 이름 한 줄씩 입력 (엑셀 두 칸 복사 가능) → 명단 저장
💡 비밀번호는 내 구글 시트 '설정' 탭에 저장돼요. 잊어버리면 시트를 열어 관리자비번 칸을 확인하세요.
Step 6. 학생들에게 배포
  1. ⚙️ 탭의 학생용 링크를 QR코드나 메시지로 공유
  2. 학생은 디벗·핸드폰에서 홈 화면에 추가로 앱처럼 설치 (⚙️ 탭 '학생 설치 방법' 참고)
  3. 처음 열 때 학번 한 번 등록하면 끝
  4. 상단 👀 학생 화면 버튼으로 학생에게 어떻게 보이는지 확인할 수 있어요.
  5. 교실 전자칠판엔 학생용 링크를 열고 맨 아래 🖥️ 교실 화면 모드를 켜 두세요.
💡 나중에 GAS 코드를 고칠 땐 새 배포가 아니라 배포 관리 → ✏️ 수정 → 새 버전으로 해야 기존 학생 링크가 유지돼요.
📘 설치가 끝나고 로그인하면, 관리 화면의 📘 가이드 탭에서 사용법을 볼 수 있어요.

📖 학생 설치 방법 (디벗·핸드폰)
  1. 학생용 링크를 열어요. (학급 단톡방에 올려두면 폰에서도 바로 열 수 있어요)
  2. 홈 화면에 추가해요.
    · 디벗·안드로이드 폰: 크롬 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치
    · 아이폰: 사파리 아래 공유 버튼(□↑) → 홈 화면에 추가
  3. 홈 화면에 생긴 아이콘으로 열면 앱처럼 실행돼요.
  4. 처음 열 때 학번을 한 번 등록해요. 디벗과 폰에 각각 한 번씩 등록하면 돼요.

💡 [확인했어요] 기록은 학번 기준이라 디벗·폰 어디서 눌러도 똑같이 반영돼요.
⚠️ 링크만 있으면 공지가 보이니, 학생들에게 링크는 우리 반끼리만 공유하도록 안내해 주세요.

🖥️ 전자칠판: 학생용 링크를 열고 맨 아래 [🖥️ 교실 화면 모드] → 담임 비밀번호나 회장 코드 입력. 모든 호출이 크게 뜨고 오늘 호출은 상단에 계속 남아요. 처음 한 번 화면을 터치해야 알림음이 나요.

🚨 긴급오늘 꼭 알아야 할 것 (교실 변경, 일정 급변경)맨 위 빨간 배너. "팝업 알림"을 켜면 앱을 켜 둔 학생에게 팝업❌

📋 학급공지제출물·회신처럼 마감이 있는 것날짜 = 마감일. 마감 전까지 "마감 전 학급공지"에 보이고 D-day 표시⭕

📌 일반그 밖의 안내그날 목록에 표시⭕
💡 모든 유형(호출 제외)은 기간으로 올릴 수 있고, ⭐ 중요를 켜면 학생에게 확인을 받을 수 있어요.
✏️ 공지 올리기 (기간 · 중요 · 사진·링크)
기본
  1. ✏️ 공지 탭 → 유형 고르기 → 날짜 → 제목 → 내용 → 공지 올리기
  2. 제목은 학생 목록에 보이는 한 줄이에요. 짧은 내용(3줄·80자 이내)은 목록에 바로 보이고, 길면 눌러서 봐요.
📅 기간으로 올리기
  1. 날짜 아래 ☑ 기간으로 올리기 → 종료일 선택 (처음엔 일주일로 잡혀요, 최대 90일)
  2. 기간 동안 매일 학생 "오늘" 탭에 보이고, 카드에 "~10/5까지"가 붙어요. (호출은 기간 불가)
⭐ 중요 — 학생 확인 받기
  1. 체크하면 학생 공지 안에 [확인했어요] 버튼이 생겨요.
  2. 📊 확인현황 탭에서 누가 안 봤는지 명단으로 볼 수 있어요.누가 확인했는지는 담임선생님이 볼 수 있어요.
📎 사진·링크 첨부 (최대 5개, 사진 3장)
  1. 📷 사진 선택: 폰 갤러리·카메라에서 골라요. 자동으로 줄여서 올라가요.
  2. + 링크·사진 주소: 설문지·문서 링크나 드라이브 사진 주소를 붙여넣어요. 드라이브 사진은 "링크가 있는 모든 사용자"로 공유해야 보여요.
  3. 글씨가 아주 많은 문서는 사진보다 PDF·문서 링크가 더 선명해요.
🔔 같은 날짜·과목 알림
  1. 같은 날짜에 같은 과목 공지가 이미 있으면 올리기 전에 물어봐요.
  2. 기존 공지에 내용 추가 / 이 내용으로 바꾸기 / 올리지 않기 중에서 골라요.
수정·삭제
  1. 공지 목록에서 [수정] [삭제]. 회장은 본인이 쓴 공지만 고칠 수 있어요.회장은 본인이 쓴 공지만 고칠 수 있어요.
📋 카톡 목록을 한 번에 올리기

"9월 22일(월): 수학 발표" 같은 목록을 통째로 붙여넣으면 날짜별 공지로 나눠서 달력에 올려 줘요.

방법
  1. 공지 탭 아래 📋 목록 붙여넣기로 한 번에 올리기 → 유형 고르기 → 붙여넣기 → 읽어오기
  2. 미리보기에서 날짜·제목을 확인하고 → 선택한 공지 올리기
  3. 공지 작성 칸에 붙여넣어도 "날짜별로 나눌까요?"라고 알아서 물어봐요.
  • "○월 ○일 공지" 같은 머리말 줄, 날짜 없는 줄은 자동으로 빠져요.
  • "9월~10월: 탐구 진행"처럼 기간인 줄은 시작 달 1일에 들어가요.
  • 적힌 요일이 실제 요일과 다르면 ⚠️ 경고가 떠요. 날짜를 한 번 더 확인해 주세요.
  • 이미 올라간 공지와 겹치면 줄마다 추가 / 바꾸기 / 올리지 않기를 고를 수 있어요.
📣 호출 · 🖥️ 전자칠판
호출하기
  1. 유형 호출 → 명단에서 학생 체크 (또는 "학급회장"처럼 직접 입력) → 내용 → 올리기
  2. 날짜가 오늘이고 팝업 알림이 켜져 있으면(호출은 기본으로 켜져요), 앱을 켜 둔 그 학생 기기에 팝업이 떠요.
✅ 다녀왔어요
  1. 다녀온 학생이 칠판의 호출 칸이나 자기 기기에서 자기 이름을 눌러 체크해요. 잘못 눌렀으면 한 번 더.
  2. 공지 목록에 "다녀옴 1/2"처럼 표시돼요.
🖥️ 교실 화면 모드 (전자칠판)
  1. 칠판에서 학생용 링크 열기 → 맨 아래 🖥️ 교실 화면 모드 → 담임 비번 또는 회장 코드
  2. 모든 호출이 크게 뜨고, 오늘 호출은 맨 위 한 줄에 남아요. 30초마다 새로고침돼요.
  3. 처음 한 번 화면을 터치해야 알림음이 나요.
  4. 칠판에서 공지를 쓰려면 위쪽 ✏️ 관리 → 비번. 다 쓰면 🖥️ 교실 화면 모드로 돌아와요. 5분 동안 조작이 없으면 자동으로 돌아와요.
📊 확인현황 · 학생 수정 요청
  • 📊 확인현황: ⭐ 중요로 올린 공지마다 확인한 학생 수와 미확인 명단이 보여요.
  • 학생 수정 요청·질문: 학생이 공지 안에서 보낸 질문이 공지 탭 위쪽에 모여요. 학번·이름이 함께 와요. 공지 제목을 누르면 바로 수정 화면으로 가고, 다 하면 [처리 완료].
  • 회장은 회장이 쓴 공지에 온 요청만 보고 처리할 수 있어요.
🙋 회장에게 알려 줄 것
  • 회장은 관리자 링크 + 회장 코드로 들어와요. 회장이 바뀌면 ⚙️에서 회장 코드만 바꾸면 이전 회장은 못 들어와요.
  • 할 수 있는 것: 학급공지·교과공지·일반 올리기, 기간·사진·링크, 목록 한 번에 올리기, 본인 글 수정·삭제
  • 못 하는 것: 긴급·호출, 명단·설정, 확인현황
  • 회장이 로그인하면 이 가이드에서 회장에게 필요한 부분만 보여요.
⚙️ 그 밖의 설정
  • 🔗 우리 반 앱 바로가기: 내가 쓰는 학급 앱 주소를 넣으면 학생 화면·칠판에 버튼으로 떠요.
  • 📷 사진 저장 현황: 사진은 내 구글 시트에 저장돼요. 가끔 사진 정리하기로 90일 지난 공지 사진을 지워 주세요.
  • 관리자 비밀번호는 ⚙️ 학급 설정에서 바꿀 수 있어요.
🛠️ 이럴 땐 이렇게 (문제 해결)
  • "저장 중…"이 오래 걸려요 → 구글 서버가 느릴 때가 있어요. 몇 초째인지 표시되고, 1분 안에 결과를 알려 줘요. 실패로 나와도 다시 눌러도 두 번 올라가지 않아요.
  • 맨 위에 🔔 "GAS 코드 업데이트가 필요해요" → 앱이 업그레이드된 거예요. [업데이트 방법 보기]를 따라 3분이면 끝나요.
  • 🔔 업데이트 알림이 보여요 → 담임선생님께 알려 주세요.
  • 비밀번호를 잊었어요 → 내 구글 시트의 '설정' 탭 → 관리자비번 칸에서 확인할 수 있어요.
  • 로그인 화면이 바로 떠요 (공용 PC) → 다른 선생님 연결이 남아 있는 거예요. [연결 주소 변경]에 내 GAS 주소를 넣어 주세요.
  • 사진이 안 보여요 → 드라이브 사진은 공유 설정을 "링크가 있는 모든 사용자"로. 앱에서 올린 사진은 [다시 시도]를 눌러 주세요.
  • 학생이 "서버에 연결하지 못했어요" → 학교 와이파이가 막는 경우가 있어요. 데이터로 바꾸거나 크롬으로 열어 보게 해 주세요.
  • 화면이 예전 그대로예요 → Ctrl + F5 (폰은 새로고침)

🔔 GAS 코드 업데이트

새 기능이 제대로 동작하도록, 내 구글 시트의 코드를 최신으로 바꿔요. 공지·명단 등 기존 데이터는 그대로예요.

1. 새 코드 복사
2. 붙여넣기 → 저장
  1. 내 구글 시트 → 확장 프로그램 → Apps Script
  2. 편집기의 코드를 Ctrl+A로 전부 지우고 붙여넣기 → 저장(💾)
3. 수정 배포 (꼭!)
  1. 오른쪽 위 배포 → 배포 관리
  2. ✏️ 수정 → 버전: 새 버전 → 배포
⚠️ 새 배포를 누르면 주소가 바뀌어서 학생 링크가 끊겨요. 꼭 수정으로 해 주세요.
