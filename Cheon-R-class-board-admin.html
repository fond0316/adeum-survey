학급 공지 관리

📱 학생용 링크

이 링크를 QR코드나 메시지로 학생들에게 보내 주세요.

📖 학생 디벗 설치 방법
  1. 학생용 링크를 크롬(또는 삼성 인터넷)으로 열어요.
  2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치를 눌러요.
  3. 홈 화면에 생긴 아이콘으로 열면 앱처럼 실행돼요.
  4. 처음 열 때 학번을 한 번 등록해요.
  5. 호출 알림을 잘 받으려면 수업 중에 앱을 켜 두게 안내해 주세요. (닫혀 있으면 다음에 열 때 떠요)

⚙️ 학급 설정

학생 화면 상단에 2026학년도 1학년 4반처럼 표시돼요.

회장이 바뀌면 코드만 바꾸면 돼요. 이전 코드는 바로 사용할 수 없어요.
