🔗 구글 시트 연결

Apps Script에서 배포한 웹 앱 URL을 붙여 넣어 주세요.

📖 CLASS BOARD 설치 가이드

Step 1. 구글 시트 만들기
  1. 구글 계정 로그인 → 구글 스프레드시트 접속 → 새 스프레드시트 만들기
  2. 이름은 자유롭게 (예: CLASS BOARD 2026 1-4)
  3. 시트 탭은 직접 만들 필요 없어요. 첫 연결 때 자동으로 생겨요.
Step 2. GAS 코드 붙여넣기
  1. 시트 메뉴 확장 프로그램 → Apps Script
  2. 편집기에 있는 기본 코드를 Ctrl+A로 전부 지우기
  3. 아래 코드 전체 복사 버튼 → 붙여넣기 → 저장(💾)

불러오는 중…
Step 3. 웹 앱으로 배포
  1. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
  2. 실행 사용자: 나 / 액세스 권한: 모든 사용자 → 배포
  3. 권한 요청 창: 내 계정 선택 → 고급 → (안전하지 않음)으로 이동 → 허용
  4. 마지막 화면의 …/exec로 끝나는 웹 앱 URL 복사
Step 4. 연결하기
  1. 이 화면에서 ← 돌아가기 → 복사한 URL 붙여넣기 → 연결하기
  2. 처음 비밀번호 0413으로 로그인
  3. 처음 한 번 사용자 등록(이름·학교·학급)을 해요
⚠️ 링크를 열었는데 연결 화면 없이 로그인 화면이 바로 뜬다면, 이 기기에서 다른 선생님이 쓰던 연결이 남아 있는 거예요. (예: 교무실 공용 PC) 로그인 화면의 [연결 주소 변경]을 눌러 내 URL을 붙여넣어 주세요.
Step 5. 첫 설정
  1. ⚙️ 설정 탭에서 관리자 비밀번호 변경
  2. 학년도·학급 이름·회장 코드 입력 → 설정 저장
  3. 👥 명단 탭에 학번 이름 한 줄씩 입력 (엑셀 두 칸 복사 가능) → 명단 저장
⚠️ 비밀번호를 바꾸지 않으면 0413을 아는 누구나 관리자로 들어올 수 있어요.
Step 6. 학생들에게 배포
  1. ⚙️ 탭의 학생용 링크를 QR코드나 메시지로 공유
  2. 학생은 크롬 ⋮ 메뉴 → 홈 화면에 추가로 앱처럼 설치
  3. 처음 열 때 학번 한 번 등록하면 끝
  4. 상단 👀 학생 화면 버튼으로 학생에게 어떻게 보이는지 확인할 수 있어요.
💡 나중에 GAS 코드를 고칠 땐 새 배포가 아니라 배포 관리 → ✏️ 수정 → 새 버전으로 해야 기존 학생 링크가 유지돼요.

📝 사용자 등록

처음 한 번만 등록하면 돼요. 입력한 정보는 사용 현황 파악을 위해 개발자에게 전달되며, 학생 정보는 전달되지 않아요.

📱 학생용 링크

이 링크를 QR코드나 메시지로 학생들에게 보내 주세요.

다른 선생님은 이 링크로 들어가서 설치 가이드를 따라 본인 시트를 연결하면 돼요.

📖 학생 디벗 설치 방법
  1. 학생용 링크를 크롬(또는 삼성 인터넷)으로 열어요.
  2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치를 눌러요.
  3. 홈 화면에 생긴 아이콘으로 열면 앱처럼 실행돼요.
  4. 처음 열 때 학번을 한 번 등록해요.

⚙️ 학급 설정

학생 화면 상단에 2026학년도 1학년 4반처럼 표시돼요.

회장이 바뀌면 코드만 바꾸면 돼요. 이전 코드는 바로 사용할 수 없어요.
